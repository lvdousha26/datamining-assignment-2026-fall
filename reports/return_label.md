# 换标签实验：次日超额收益（这才是真正有信息量的问法）

> 2026-11-11｜2,568 条公告｜时间切分 2,054 训练 / 514 评估｜同一批 3,000 条样本

## 0. 为什么必须换标签

用「预告类型」（预增/预减）当标签时，正文里写着「同比增长 120%」，模型只需读数字：
表格基线 93.2%、BERT 89.2%、10 行正则 84.6%——**文本根本没有增量**。

换成「公告后市场怎么走」以后，公告说什么不再等于市场怎么反应，**预期差**才是。
这时文本才第一次有资格提供数字之外的信息。

## 1. 口径

| 项 | 定义 |
|---|---|
| 事件日 | `公告日期`；t0 = 公告日当天或之前最近的交易日（盘后公告按当日算） |
| 反应窗口 | t1 = 下一个交易日，收益 = 收盘到收盘 |
| 超额 | 个股 t0→t1 收益 − 当日全市场等权收益（与 Y2 基准同口径） |
| 3 分类 | 超额 > +1% 利好；< −1% 利空；其余中性 |
| 切分 | **按日期** 80/20（2016-02~2025-01 训练，2025-01~2026-10 评估） |

按日期切而不是随机切：同一天的公告共享同一波市场冲击，随机切会把评估日的信息漏进训练集。

样本：3,000 条里 **2,568 条**可用（432 条停牌/退市/无次日行情）。3 类分布意外地均匀：
中性 904 / 利空 861 / 利好 803，评估集多数类 35.6%。

## 2. 第一个关键数字：旧标签与新标签一致率 35.7%

| 指标 | 数值 |
|---|---|
| 「预告类型方向」与「次日超额方向」一致率 | **35.7%** |
| Spearman（预告方向 vs 超额收益） | **0.136** |

3 分类瞎猜是 33.3%，35.7% 只高 2.4pp。**公告说什么，和市场当天怎么走，几乎无关。**
这就是预期差的直接度量——也是「业绩预告情感分类」这个课题最该先看到的数字。

## 3. 同一批模型，换标签后的结果

| 模型 | 预告类型标签 | **次日超额标签** |
|---|---|---|
| 多数类基线 | 61.0% | **35.6%** |
| 关键词正则 | 84.6% | 35.2% |
| TF-IDF + LR | 88.2% | 35.2% |
| LightGBM（纯数值表格） | 93.2% | **34.4%** |
| BERT-base-chinese | 89.2% | **35.8%** |

**全部落在多数类基线上，一个都没跑赢。** 特别注意表格基线：从 93.2% 掉到 34.4%——
这是最有说服力的一行，因为它说明上一版 93.2% 的来源不是"预测能力"，是"数字和标签同构"。

## 4. 稳健性：换阈值、换窗口都不改变结论

3 分类的 ±1% 阈值是我拍的，所以补一组二分类 + AUC（AUC 不受阈值影响）：

| 目标 | 涨占比 | LR(AUC) | LGBM 表格(AUC) |
|---|---|---|---|
| 次日超额 > 0 | 51.8% | **0.5546** | 0.5222 |
| 5 日超额 > 0 | 56.8% | 0.4572 | 0.4991 |

- 次日二分类：LR 的 AUC 0.555，比随机高 0.05，514 个评估样本下标准误约 0.025，**约 2σ，勉强算个弱信号**；
  表格只有 0.522。
- 5 日二分类：LR 掉到 0.457（低于随机，说明是过拟合的噪声），表格 0.499——**完全无效**。

也就是说：文本里可能有极弱的一点次日方向信息，但**撑不过 5 天**。
这和主模型的结论一致——多因子模型 5 日 IC 0.10，靠的是「垫底那一撮」的负超额，不是方向预测。

## 5. 结论

1. **旧标签（预告类型）上的高分是假象**：93.2% 来自"读数字"，与预测市场无关。
2. **新标签（次日超额）上所有模型归零**：3 分类 34~36%，二分类 AUC 0.46~0.55。
3. **一致率 35.7%** 是这个课题的核心事实：公告方向 ≈ 随机，市场反应由预期差决定，
   而预期差不在公告正文里——它在公告之外的持仓、预期、和市场状态里。
4. 这条负结果比任何 90% 的准确率都有价值：**它说明该换数据源，而不是换模型**。
   想做有预测力的文本因子，得拿「卖方一致预期」「调研纪要」「互动易问答」这类**增量信息**，
   而不是交易所强制披露、人人可见的业绩预告。

## 6. 局限

- 次日超额标准差 **6.33%**，信噪比极低，单日窗口天然难预测；5 日窗口也不行，说明不是窗口问题。
- 公告时点只有「日期」没有「时分」，盘中公告会被算成盘后反应，引入噪声（方向随机，不偏）。
- 2,568 条里 2016~2025 占 80%，市场结构变化（注册制、涨跌幅改革）没有分层处理。
- 二分类 AUC 0.555 只在一个 514 条的评估段上测过一次，没有第二段确认，只能算"值得再测"，不能算结论。
