# A3 · 聚类三件套（肘部 / 轮廓 / bootstrap ARI）

> 2026-11-14｜样本 **4914 只 × 42 因子**｜区间 2025-01-01 ~ 2025-06-30（117 个交易日，dev 段）

## 口径

1. 每只股票先做**逐日截面 z-score**（消掉全市场同涨同跌），再对区间取均值 → 42 维「性格向量」，与当期涨跌无关；
2. 维度间再标准化，欧氏距离，KMeans（n_init=10）；
3. 轮廓系数在 4000 只上算（全量 O(n²) 没必要）；
4. bootstrap：抽 80% 股票重聚类 100 次，与全样本标签算 ARI（1=完全一致，0=随机）。

## 怎么读这三个数

- **ARI 才是关键**。轮廓系数只说明「这次分得开」，ARI 说明「换一批股票还分不分得开」。ARI < 0.6 意味着聚类结果对样本高度敏感，拿它做中性化分组要打折扣。
- 本项目把聚类 31 组当行业代理，但那 31 组是按**收益相关性**聚的（`ind_rolling.py`），这里的 k 是按**因子画像**聚的，两个数不冲突，但**不能互相替代**：前者管风险，后者管风格。
- 轮廓系数在 5000 只、42 维上天然偏低（0.1~0.3 是常态），不要拿它跟二维玩具数据比。

## 取舍：肘部说 4、轮廓说 2，听谁的

两者不一致是常态：轮廓系数偏好**分离度高的小簇**，在 42 维、5000 个点上会一路偏向 k=2；
肘部看的是**边际收益**（再增加一个簇能省多少簇内平方和），更贴近「分几组够用」。
**结论：用 k=4**，因为后续用途是「组内去均值的中性化 / 风格分桶」，需要的是可解释的粗分，
不是统计上最分离的二分；而且 k=4 的 bootstrap ARI 0.963，稳定性远好于 k=31 的 0.392。

## 各簇的用途

- **做中性化的分组**：不建议（`neutral_switch.md` 证明三种分组的中性化都让 CV 下降）；
- **做风格分桶分析**：可以，用来看「哪一类股票在亏钱」，比如 D1 里若集中在某两簇，说明是风格暴露；
- **不要**拿它当行业代理：它按因子画像聚，不是按业务分类。
