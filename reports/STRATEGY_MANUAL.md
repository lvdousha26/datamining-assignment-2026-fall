# 第〇部分 · 核心配置（直接用这个）

> **2026-11-07 修订：上一版的「A1 70% + A2 30%」已撤回。** 原因是 A2 的绝对收益用了沪深300 近似基准，
> 把它的波动低估了一倍。用逐日持仓模拟重算后，A2 的真实波动是 23.75%、回撤 −45.5%，
> 加入组合只会降夏普。详见 `reports/abs_return_fix_report.md`。

**当前结论：只跑 A1（策略③），A2 不加入组合。**

| | 年化 | 波动 | 夏普 | 最大回撤 |
|---|---|---|---|---|
| **A1 策略③** | **+11.92%** | **9.40%** | **1.06** | **−10.3%** |
| A2 质量+估值 | +11.60% | 21.45% | 0.45 | −38.8% |
| 全市场等权（剔次新） | +5.78% | 23.60% | 0.16 | −46.6% |
| 沪深300 | +2.21% | 18.36% | 0.01 | −45.6% |

（2016-01 ~ 2026-10，130 个月，费后；A1↔A2 月收益相关 0.445）

**为什么不是 70/30**：A2 的超额是真的（相对同频等权 +7.33%/年，alpha +7.45%，beta 0.86），
但它的波动是 A1 的 2.5 倍，而两者相关性只有 0.445，分散化补不回波动差。夏普最优权重 **0%**。
给 A2 加波动目标（`clip(10%/近6月波动, .2, 1)`）也只能让夏普持平，收益还降 0.4 个点。

### 执行方式

```
每月最后一个交易日收盘后，只跑 A1：

  1. 纳指趋势线动量   26%   → w = clip(0.5 + 10×dev, 0, 1)，dev>1.2 封顶 50%
  2. 纳指 MA125      26%   → 纳指>125日均线则满仓，否则 0
  3. 红利低波        13%   → 常持（512890）
  4. 上证丹尼斯      13%   → 破90日新高满仓 / 破40日新低清仓
  5. 伯克希尔        11%   → 常持
  6. 黄金           11%   → 常持
```

### A2 的定位（可作为独立卫星，不进主组合）

如果不满足于 A1 的 11.9%/9.4%，想额外承担风险换 alpha，可以把 A2 当**独立账户**跑，
但它要单独承担 24% 波动和 −45% 回撤：

```
质量分（6 因子 z 等权）≥ 60% 分位 → 池子
池内按估值分（5 因子 z 等权）降序取 300 只
每申万一级 ≤ 5%（15 只）
等权，每 60 个交易日换仓
剔除 ST、上市不满 60 个交易日
```

实测：+11.65%/年，波动 23.75%，夏普 0.41，最大回撤 −45.5%，换手 38%/次（年化成本 0.46%）。

### 分年（净收益 %，A1 vs A2）

| | 2016 | 2017 | 2018 | 2019 | 2020 | 2021 | 2022 | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| **A1** | 4.7 | 20.5 | **−2.3** | 18.6 | 26.1 | 12.7 | **−7.5** | 19.8 | 20.6 | 18.8 | 2.7 |
| A2 | 13.3 | −1.2 | **−31.2** | 39.7 | 25.3 | 46.2 | −1.1 | 14.2 | 24.2 | 22.1 | −3.4 |

A1 最坏一年 −7.5%，A2 最坏一年 −31.2%。**这就是加不加它的分水岭。**

# 第一部分 · A 级组件（2 个）

## A1 策略③（六腿配置）

**逻辑**：美股吃 beta + A 股吃红利低波/趋势突破，不做择时预测，只做仓位调节。

### 腿与权重（合计 100%）

| 腿 | 权重 | 规则 | 明细 |
|---|---|---|---|
| 纳指趋势线动量 | 26% | `w = clip(0.5 + 10×dev, 0, 1)` | `dev = log(纳指 / 纳指20年趋势线)`；dev>1.2 时仓位**封顶 50%**（泡沫保险） |
| 纳指 MA125 择时 | 26% | 纳指 > 125 日均线 → 满仓；否则 0 | 二元开关 |
| 红利低波 | 13% | 常持 | ETF 512890（2019 前用中证红利全收益 H00922 代理） |
| 上证丹尼斯 | 13% | 90/40 突破 | 收盘破 90 日新高 → 满仓；破 40 日新低 → 清仓 |
| 伯克希尔 | 11% | 常持 | BRK-B（人民币口径，含汇率） |
| 黄金 | 11% | 常持 | COMEX 黄金（人民币口径） |

### 执行

- **频率**：月频，每月最后一个交易日收盘后算信号，次日执行
- **脚本**：`live_signal.py`（打印目标仓位）、`spec3.py`（回测）
- **成本**：单边 5bp
- **业绩**：11.08% / 波动 9.78% / 夏普 0.93 / 回撤 −22.5% / Calmar 0.49（2007-02~2026-10）
- **已过检验**：CSCV/PBO、Deflated Sharpe、参数扰动、分半 OOS

### 不做什么

- 不加信用利差条款（实测 2007/2013/2019 三窗口均无正贡献，已设 `CSS_BETA=0`）
- 不调参数（`tune5` 已跑 2250 组网格，参数在邻域内平坦）
- 不加 TAA（与③相关 0.75，加了降夏普）

## A2 质量 + 估值长线

> 组合里用「风险预算版」：权益仓位按波动目标动态调整。

### 波动预算（组合用这一版）

```
w_equity = clip(0.08 / 近6月实现波动, 0.20, 1.0)
剩余 = 1 - w_equity，配 国债 70% + 黄金 30%
```

实测把 A2 的夏普从 **0.64 提到 1.00**，年化没掉（13.24%→13.39%），因为它在 2018/2022 自动减仓。

### 选股规则

**逻辑**：先用质量筛掉烂公司，再在好公司里挑便宜的。季度换仓，换手 2.7 倍。

**因子定义（全部 PIT，按公告日）**：

**质量分**（6 因子等权 z，至少 3 个有效）：
| 因子 | 定义 | 方向 |
|---|---|---|
| roe_ttm | 净利润 TTM / 股东权益 | 高好 |
| gpa | (营收 TTM − 营业成本 TTM) / 总资产 | 高好 |
| ocf_ni | 经营现金流 TTM / 净利润 TTM（仅盈利公司） | 高好 |
| accrual | (净利润 − 经营现金流) / 总资产 | **低好** |
| debt_ratio | 资产负债率 | **低好** |
| roe_stab | 过去 12 季 ROE 标准差 | **低好** |

**估值分**（5 因子等权 z，至少 2 个有效）：`bp`（净资产/总市值）、`ep`（净利润/总市值）、`sp`（营收/总市值）、`ocf_yield`（经营现金流/总市值）、`fcf_yield`（(经营+投资现金流)/总市值）

### 选股规则

```
1. 剔除：ST、上市不满 1 年、停牌
2. 质量分 ≥ 当日 60% 分位（即前 40%）→ 池子
3. 池内按估值分降序取前 300 只
4. 等权买入
4. **每申万一级行业最多 15 只（=5% 权重）** ← 这一条白捡了 +0.83pp 年化
5. 每 60 个交易日（≈季度）重新执行 1-4
```

### 执行

- **数据**：`data/big/fin_panel.parquet`（21 个 PIT 因子，1109 万行）
- **脚本**：`long_strategy.py`
- **成本**：单边 15bp
- **业绩（加行业约束后）**：**+10.75% 超额 / 波动 9.21% / 夏普 1.17 / 回撤 −9.7% / 换手 2.71 倍**（2016-04~2025-06，38 季度）
- 加约束前：+9.92% / 9.63% / 1.03 / −12.2% —— 约束反而提升收益，因为防住了单一低估值行业的价值陷阱
- **绝对收益（含 beta）**：13.39% / 11.40% / 夏普 1.00 / −14.2%（加 8% 波动预算后）

### 已知缺陷（实盘前必须处理）

1. **无行业约束** → 纯估值 top300 会重仓银行、地产、公用事业。建议每个申万一级 ≤15%
2. **质量分 4/6 因子无效**（gpa/accrual/debt_ratio/roe_stab 的 IC ≈ 0）→ 建议只留 roe_ttm + ocf_ni，或改成排除项（商誉/净资产>30% 剔除、应收增速>营收增速×1.5 剔除）
3. **2024 年 −5.2%**，价值因子有真实失效风险
4. 只有 38 个季度，t ≈ 2，勉强显著

# 第二部分 · B 级（有正超额，7 个）

## B1 禁买清单（量价模型）

**逻辑**：不选股，只把模型认为会跌的 10% 剔掉。

### 规则

```
1. 全 A 池（约 5059 只有效）
2. 打分 = Ridge 元模型（0.497×LGBM + 0.476×TF + 0.124×因子合成）
3. 剔除打分最低 10%（约 505 只）
4. 每 5 个交易日重算
5. 你原本要买的票如果在名单里 → 不买/减掉
```

### 执行

- **脚本**：`live_screen.py`（输出 `live/screen_YYYY-MM-DD.csv`，`is_d1=1` 即禁买名单）
- **模型**：`checkpoints/lgbm_big.txt` + `tf_seed{1,2,3}.pt` + `reports/big_models_meta.json`
- **业绩**：封存段 318 日 +2.87% / 夏普 0.53 / 换手 5.4%；2024-25H1 +6.55% / 夏普 4.08
- **成本**：单边 15bp，对结果影响 <1%
- **优势**：零额外交易（不买就是省钱）

## B2 / B3 行业内剔底

规则同 B1，但把「全市场排序取垫底 10%」换成「每个行业内各自取垫底 10%」。

| 口径 | 年化 | 波动 | 夏普 | 换手 |
|---|---|---|---|---|
| 聚类 31 组 | +5.57% | 1.08% | **5.16** | 6 倍 |
| 申万 128 个 | +2.86% | 0.72% | 3.97 | 3 倍 |

**用聚类，不要用申万**（128 组日均 26 只，剔 10% 只剩 2-3 只，噪声盖过信号）。脚本 `strategy_compare.py`。

## B4 TAA v3（ERP 择时）

### 规则

```
1. 资产：沪深300 / 中证1000 / 纳指 / BRK（风险）+ 国债 / 黄金（防御）
2. ERP = 100 / 沪深300 PE-TTM − 国债收益率
3. q = ERP 过去 60 个月的滚动分位
4. 风险预算 b = clip(0.2 + 0.8×q, 0.2, 1.0)
5. 风险资产各 b/4 等权；防御部分配给动量最强的 1 个（国债或黄金）
6. 月频
```

**业绩**：6.79% / 9.82% / 夏普 0.49 / 回撤 −22.6% / 换手 9%/月。脚本 `taa_v3.py`。

**判断**：能跑，但不如策略③，且相关 0.75 → **不加**。

## B5 格雷厄姆 PE 择时（沪深300）

```
PE-TTM 历史分位 < 15% → 满仓沪深300
PE-TTM 历史分位 > 80% → 逐月减仓（每 5% 减 1/3）
跌破 MA200 → 清仓（熊市条款）
```

8.02% / 夏普 0.30 / **超额 t +3.24**。脚本 `val_timing.py`。

## B6 上证趋势线（line）

```
dev = log(上证 / 上证 20 年趋势线)
w = clip(0.5 + k×dev, 0, 1)，k = 5
月频
```

7.21% / 夏普 0.34 / **超额 t +3.23** / 换手 100%/年。全样本（1996-2026）8.99% / 0.42。脚本 `bt1.py`~`bt9.py`。

## B7 恒生趋势线反转（k=5）

同上，但 **sign = −1**（反转而非动量）。4.86% / 夏普 0.16 / **超额 t +3.96**。样本波动大，慎用。

# 一句话

**能赚钱的只有两个**：策略③（11.08%/0.93）和质量+估值长线（超额 +10.75%/1.17）。把它们按 **70/30** 复合成一个组合，得到 **13.63% / 波动 8.59% / 夏普 1.35 / 回撤 −9.3%**——这是本项目最终的推荐形态。

其余 146 个脚本里，7 个有正超额但不值得单独立户，16 个已经证伪，15 个还没证明，100 个是工具。
