# 通用事件研究框架 · 使用指南

> 2026-11-09｜`scripts/event_study.py` + `scripts/make_events.py`
> 给一个 (股票, 日期, 事件描述) 列表，自动输出 CAR 表 + 安慰剂分位 + 同侪排序

---

## 一、两个脚本

| 脚本 | 作用 |
|---|---|
| `event_study.py` | 事件研究的执行引擎：CAR、安慰剂、同侪、汇总统计、图表 |
| `make_events.py` | 事件表生成器：从财务面板自动挖「财报惊喜」，或从收益矩阵挖「放量异动」 |

---

## 二、输入格式

最小事件表（CSV，两列就够）：

```csv
symbol,date
601155,2019-07-03
002594,2022-08-24
```

带事件类型（推荐，可按类型分组统计）：

```csv
symbol,date,label,note
601155,2019-07-03,实控人丑闻,王振华被拘
002594,2022-08-24,大股东减持,伯克希尔首次减持
601318,2021-02-04,信用风险,华夏幸福债务敞口
```

`label` 会作为分组键出现在汇总表里；`note` 只做备注。

## 三、三种用法

### ① 手填事件（案例研究）

```bash
python scripts/event_study.py --events events/demo_cn.csv --market cn
```

### ② 自动生成（批量检验）

```bash
# 从财务面板挖「财报惊喜」，每年分层取 top
python scripts/make_events.py --type earnings --top 60 --thr 1.5

# 只取低预期（负向事件）
python scripts/make_events.py --type earnings --top 100 --side neg

# 从收益矩阵挖放量异动
python scripts/make_events.py --type volume --top 200 --thr 3.0
```

### ③ 关键参数

| 参数 | 含义 | 默认 |
|---|---|---|
| `--market cn|us` | A 股走本地日收益矩阵；美股走 akshare 后复权 | `cn` |
| `--windows` | 窗口列表（交易日） | `1,5,20,60,250` |
| `--lag` | 事件日后再延几个交易日（**盘后公告用 1**） | `0` |
| `--align next|prev` | 事件日落在非交易日时取前/后 | `next` |
| `--bench ew|csi` | A 股基准：全市场等权 / 中证全指 | `ew` |
| `--peers` | 美股同侪列表文件（每行一个 ticker） | 无 |

## 四、三个指标怎么读（按顺序）

### ① 安慰剂分位 —— 先杀掉「个股本来就这样」

对每只股票，把它**全部历史**上所有同长度窗口的 CAR 算出来，看事件窗口排第几百分位。

- 分位 ≈ 50% → 事件毫无特殊之处
- 分位 < 10%（或 > 90%）→ 才算异常

> 这个指标专治「AMZN 涨了 253% 所以婚外情是利好」——它涨是因为纳指涨，不是事件。

### ② 跨事件 t 值 —— 再看「一批事件是否系统性」

`t = CAAR均值 / (截面标准差 / √N)`。**N < 10 时没有统计功效**，只能当案例。

### ③ 同侪排序 —— 最后杀掉「行业 beta」

同行业（A 股用申万一级）同期股票的超额分布，看事件股排第几。

- `peer_rank` 高 = 事件股跑输大多数同行 → 事件效应可能存在
- `peer_rank` ≈ 50% = 就是行业行情

## 五、已跑的三个案例

### 案例 1：美股 CEO 丑闻（N=2）

```bash
python scripts/event_study.py --events events/demo_us.csv --market us --peers events/peers_us.txt
```

| 股票 | CAR250 | 安慰剂分位 | 同行中位 | 同行排名 |
|---|---|---|---|---|
| AMZN（贝索斯，2019-01-09） | **−11.8%** | 16% | +4.3% | 77.8% |
| MSFT（盖茨，2021-05-17） | **+23.2%** | **96%** | +23.9% | 55.6% |

**读法**：MSFT 的 +23.2% 看着漂亮，但同行中位数 +23.9% 比它还高，排名 55.6%（中游）。
所谓「丑闻后大涨」纯粹是 2021 年科技股整体行情，与事件无关。

> 顺带修正一个旧错误：我此前用手工脚本报「MSFT 安慰剂分位 52%」，重算后是 **95.6%**，
> 手工版有 bug。这也说明为什么要做成框架——手写一次算错一次，很难发现。

### 案例 2：A 股单事件（N=5，含对照）

```bash
python scripts/event_study.py --events events/demo_cn.csv --market cn
```

| 事件 | CAR250 | 安慰剂分位 | 同侪中位 | 排名 |
|---|---|---|---|---|
| 601155 新城控股 实控人丑闻 | **−34.6%** | 12% | −23.3% | 82.8% |
| 601318 中国平安 信用风险 | **−43.5%** | **2%** | −23.2% | 94.7% |
| 002594 比亚迪 大股东减持 | −19.9% | 25% | −6.5% | 76.5% |
| 000002 万科 业绩下滑 | −22.3% | 34% | −10.2% | 82.8% |
| 600519 茅台 业绩超预期 | −15.3% | 20% | −10.0% | 65.3% |

**读法**：ALL 组 CAR250 均值 −27.1%、t=−5.22 —— 但**这是选择偏差**：事件是我按「事后已知会跌」挑的。
真正有意义的是**安慰剂分位**：只有中国平安（2%）和实控人丑闻（12%）算异常，其余都在正常范围。

### 案例 3：财报惊喜（N=110，2016-2026 每年 10 个）

```bash
python scripts/make_events.py --type earnings --top 60 --thr 1.5
python scripts/event_study.py --events events/earnings_surprise.csv --market cn --lag 1
```

次日买入口径（`--lag 1`）：

| 事件类型 | N | CAR1 | CAR5 | CAR20 | CAR60 | CAR250 |
|---|---|---|---|---|---|---|
| **财报超预期** | 55 | −0.39%（t−1.83） | **−1.49%（t−2.62）** | −1.09%（t−0.64） | −1.38%（t−0.48） | −0.43%（t−0.05） |
| 财报低预期 | 55 | +0.08%（t0.23） | +0.69%（t0.66） | +0.64%（t0.41） | −1.12%（t−0.41） | +2.70%（t0.43） |

**结论：A 股「财报超预期」公告后买入是亏的，5 日跑输市场 1.49%，t=−2.62（显著）。**

这是「利好出尽 / 短期反转」在事件层面的复现，与前面 42 因子最终塌缩成「反转 + 流动性」完全一致。

**但 250 日那一行要小心读**：均值 CAAR +1.12%，中位数 **−10.2%**。
均值与中位数反向，说明分布极度右偏——少数事件后面跟了大涨（拉高均值），
而**过半事件是亏的**。这类分布下只报均值会误导，中位数和胜率更可信。

> 必须说清的三点局限：
> 1. **SUE 是代理口径**——没有分析师预期数据，用「净利润同比相对过去 4 期的标准化偏离」代替。
> 2. **事件是极端样本**——每年只取 SUE 最高的 5 个，不代表全部超预期公司。
> 3. **没做市值/行业中性**——虽然已用同侪对照，但极端 SUE 多集中在特定行业。

### 案例 4：业绩预告（N=318，2016-2026 每年 30 个）

```bash
python scripts/make_events.py --type yjyg --per-year 15
python scripts/event_study.py --events events/yjyg.csv --market cn --lag 1
```

标签直接来自交易所强制披露的「预告类型」：预增/略增/扭亏/续盈 → 预喜；预减/首亏/略减/续亏 → 预亏。

| 事件类型 | N | CAR1 | CAR5 | CAR20 | CAR60 | CAR250 |
|---|---|---|---|---|---|---|
| 业绩预喜 | 160 | −0.02%（t−0.07） | −0.58%（t−0.83） | −0.13%（t−0.10） | +0.63%（t0.33） | −2.99%（t−0.78） |
| 业绩预亏 | 158 | +0.01%（t0.03） | +0.30%（t0.52） | **+1.78%（t1.75）** | −1.34%（t−1.06） | −2.73%（t−1.01） |

**结论：业绩预告公告后，1~250 日没有任何可交易的超额收益。**

安慰剂分位全程在 47%~57% 之间——**完全等于随机**。这是本轮最干净的一个负结果。

唯一有苗头的是「预亏后 20 日 +1.78%（t=1.75）」，方向上是「利空出尽」，
但 N=158、t 未过 2，只能算线索。

**这四个案例放在一起，能看出一条规律：**

| 事件 | 信息属性 | 5 日 CAR | t | 是否可交易 |
|---|---|---|---|---|
| 财报 SUE 极端（每年 5 个最极端） | 部分预期外 | **−1.49%** | **−2.62** | 反向有效 |
| 业绩预告（强制披露） | 完全公开 | −0.58% | −0.83 | 否 |
| CEO 丑闻（美股） | 突发 | +23.2%（但同行更高） | — | 否 |
| 实控人丑闻（A 股，N=1） | 突发 | −29.8% | — | 单案例，无法推广 |

**越是被强制披露、提前被市场消化的事件，越没有超额。**
真正有信息的是「预期之外的部分」（SUE 相对自身历史极端）和「无法提前定价的突发」（但 N 太小）。

这跟你那 42 个因子塌缩成「反转 + 流动性」是同一件事：**公开信息里没有免费的钱。**

## 六、怎么用在课程报告「事件驱动」这一章

框架本身就是那一章的核心工具，可以直接写：

1. **方法**：事件研究法（Event Study），CAR + 安慰剂 + 同侪三重对照
2. **数据**：110 个财报事件 / 5 个案例事件，覆盖 2016-2026
3. **结果**：财报超预期后 5 日 −1.49%（t=−2.62），与量价因子的反转结论一致
4. **方法论亮点**：**安慰剂检验**——绝大多数「事件研究」只报 CAR，不报安慰剂，
   这正是「AMZN 丑闻后涨 253%」这类结论能流行的原因

比单独做一个情感分类器更有说服力：**分类器告诉你标题是正面还是负面，事件研究告诉你「正面之后会怎样」。**

> 而且预告类型是**交易所强制的正负标签**，比从公告标题里猜「减持」更可靠。
