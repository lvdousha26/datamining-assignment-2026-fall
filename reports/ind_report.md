**D1 是 TMT / 成长股集中营**（通信、传媒、电子、计算机、军工全部超配 1.4-1.8 倍），
银行、钢铁、交运这些低波行业几乎不出现。这与量价画像完全一致：高换手 + 高波动 + 放量大涨。

但注意：**D1 亏得最惨的不是 TMT**——

| 行业 | D1 的 5 日平均收益 |
|---|---|
| 未分类 | -3.44% |
| 环保 | -1.79% |
| 纺织服饰 | -1.75% |
| 交通运输 | -1.72% |
| 社会服务 | -1.66% |
| …… | |
| 通信 | -0.09% |
| 电子 | -0.35% |

即：TMT 最容易**进入** D1（因为波动大、换手高），但在 TMT 里**进入 D1 反而不怎么跌**；
真正跌的是冷门行业里突然放量的票——那是「孤立异动」，没有板块承接。

## 三、行业中性化检验

| 口径 | IC |
|---|---|
| 原始 | +0.1052 |
| **行业内去均值后** | **+0.1013**（只掉 3.7%） |
| 行业层面（预测的行业均值 vs 行业实际均值） | +0.0713 |

结论：
1. **95% 以上的预测力来自行业内选股**，不是行业配置。信号不是行业影子。
2. 模型同时具备一定的行业择时能力（0.0713），但只占小头。

## 四、行业中性化后的负向筛选

| 方案 | 年化超额 | 波动 | 夏普 |
|---|---|---|---|
| 全市场剔除垫底 10% | +3.56% | 1.7% | 0.88 |
| **行业内剔除垫底 10%（行业权重不变）** | **+2.88%** | 1.28% | 0.69 |

- 只剩 81% 的效果 → 大约 **1/5 的超额来自行业配置**（模型自动低配了热门 TMT）
- 但行业内版本仍然显著为正，说明选股部分是真的

## 五、对落地的含义

1. 若组合本身有行业约束（例如跟踪沪深 300），用**行业内剔除**版本：+2.88%/年，跟踪误差 1.3%。
2. 若组合无行业约束，可以直接用全市场版本：+3.56%/年，但会顺带获得"低配 TMT"的行业暴露——
   这在 TMT 牛市里会跑输，2025 年那种行情下要能扛住。
3. 最值得单独盯的是「**冷门行业 + 突然放量**」这一类：D1 里亏得最狠（-1.7% ~ -3.4%/5 日），
   且与行业整体方向无关，是纯粹的个股异动风险。
