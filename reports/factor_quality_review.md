## 总评

**统计意义上是罕见的干净因子库；经济意义上不是 alpha 库，是一个"短期过热/反转"风险因子库。**

- 42 个因子里 **40 个通过 Bonferroni**、29 个 A 级、11/11 年符号不翻转、安慰剂检验干净通过、8 组超参 OOS IC 极差只有 0.0024。这一套统计证据在日频量价里非常硬。
- 但拆开看：**42 个因子 ≈ 12~17 个独立维度，IC 序列第一主成分解释 31%、前 3 个解释 65%**，本质是同一个 bet 的 42 种写法。强因子多空 5 日也只有 0.5~0.9 个百分点，换手却是 43%/5 日 —— **统计显著 ≠ 能赚钱**。
- 唯一稳健的落地形态仍是负向筛选（剔除垫底 10%，+3.5%/年、跟踪误差 1.7%），纯多头选股超额为负。

## 二、用户点名的三项硬检验

### 1. 小市值暴露 —— 核心因子通过，7 个是影子

口径先说清：`size` 因子实际是 `log(20日均成交额)`，是**流动性代理而非真实市值**，所以"去 size"严格说是去流动性规模。要查真市值需要接流通市值数据（尚未接入，这是缺口）。

- 全库平均市值依赖 **25%**，>50% 的 7 个（见上）
- **核心量价因子依赖极低**：dev20 4%、turn_z 9%、pvcorr20 14%、ret20 14%、mf20 16% —— 这批不是小市值影子
- 模型层面（此前已验）：去 size 后多空仍剩 **15.1% / 夏普 0.59**；行业内中性化 IC 只掉 3.7%（0.1052→0.1013），95% 是行业内选股
- 结论：**通过**。建议从因子库删掉那 7 个，避免模型把权重浪费在风格上

### 2. 未来函数 —— 收益链路干净，但有 1 个确认污染点

| 审计项 | 结论 | 证据 |
|---|---|---|
| 标签口径 | ✅ | `Y2 = close[t+6]/close[t+1]-1`，t 日收盘出信号、t+1 收盘买入（改口径后 IC 仅 0.1026→0.0960） |
| 特征时序 | ✅ | 全部 rolling/shift 只用 t 及之前；只有 `shift(-5)/shift(-6)/shift(-1)` 用于标签 |
| 截面标准化 | ✅ | `groupby('date')` 只用当日横截面 |
| TF 序列窗口 | ✅ | `make_seq = t-(L-1) … t`，方向正确，且 `samples()` 限定 t≥L 不越界 |
| 切分 | ✅ | train<2022 / meta 2022 / val 2023 / test 2024+，严格按时间 |
| 边界 embargo | ⚠️ | 5 日重叠标签会跨年边界（2021末→2022初、2023末→2024初），**缺 5 日 embargo**，影响很小但按标准该补 |
| 复权口径 | ⚠️ | 东财 `qfq` 前复权隐含未来除权信息；对收益率比例无偏，但 `pos250/dev` 等价格水平类因子在除权点有口径漂移 |
| **行业分类** | ❌ | `ind_map` 用的是**当前**申万成分，回溯套到 2016，是确认的前视污染（好在中性化 IC 只掉 3.7%，影响有限） |
| ST / 停牌复牌 | ⚠️ | 未剔除，会污染 D1 画像 |
| **inf 脏标签** | ❌→✅已修 | 见下一节 |

### 3. 过拟合 —— 模型没过拟合，评估流程过拟合了

| 检验 | 结果 | 判定 |
|---|---|---|
| IS / OOS 衰减 | 训练内 IC 0.1501 → 2024+ 0.1005，衰减 **33%** | ✅ 温和 |
| 分年度 IC | 2022 .1094 / 2023 .1122 / 2024 .1052 / 2025 .1069 / 2026 .1030 | ✅ 5 年不衰减 |
| **标签安慰剂** | 真标签 OOS **+0.0998** vs 日内打乱 **-0.0122** | ✅ 干净通过 |
| **超参敏感度** | 8 组（leaves 15~127 × min_data 100/500）OOS IC **0.0973~0.0997**，极差 0.0024、std 0.0009 | ✅ 无尖峰，不是调参调出来的 |
| Block bootstrap | Stacking IC 0.1069，20 日块 2000 次，95%CI **[0.081, 0.124]**，t=9.8 | ✅ 不是自相关假象 |
| 特征增益集中度 | Top5 40.2%、Top10 57.2%（turn5 15.1%、turn_std20 8.8%、vwap_dev 7.8%） | ⚠️ 偏集中 |

**但必须扣分的一项**：2024+ 名义上是 OOS，实际上已经被用来做几十次决策 —— 成本假设、去 size、行业中性化、十分位结构、流动性分层、涨跌停过滤、单因子 vs 模型、剔除比例……每看一次、每按结果调整一次，测试集就往样本内挪一点。这叫 **adaptive overfitting / test-set leakage**，是本次评价里最该扣的分。

**结论**：模型本身的过拟合控制做得比大多数研究扎实；**真正的风险是研究流程把唯一的样本外看透了**。解决办法只有一个 —— 封一段从未碰过的数据（例如 2026 全年、或跨市场港股/美股）做最终一次性验证。

## 三、本轮查出的真实数据 Bug：inf 扩散

这是这次审查最有价值的发现。

- 原始 1152.6 万行里，有 **13505 行 `close<=0`（0.117%）**，来自 70 只长期停牌股、1548 个交易日、全部在 2015–2021
- `fwd5_lag = close.shift(-6)/close.shift(-1)-1` 遇到分母 0 → `inf`
- 紧接着 `df.groupby('date')['fwd5_lag'].transform(lambda s: s - s.mean())`：`s.mean()` 一旦是 inf，**当日全市场每个样本都变成 ±inf**
- 结果：**82 个交易日 100% 的样本都是 inf**，共 **231159 条（2.30%）**脏标签，扩散了 17 倍
- 这些天在评估里因 y 是常数被 `spearmanr` 静默丢弃（打分卡第一版 `mono`/`LS` 全变 NaN 就是这个原因），但在训练里被 `rankdata` 赋成并列秩 —— 等于给 2.3% 训练样本灌了噪声

**影响范围**：inf 全部在 2016–2021，**2024+ 测试集一行都没有**。数值复核：4 个模型的 OOS IC 在"含 inf / 剔除 inf"两种口径下完全一致（0.0550 / 0.0996 / 0.1017 / 0.1052），**所有已发布的样本外结论不受影响**。

**已修复的代码**（不需要为此重训）：

| 文件 | 改动 |
|---|---|
| `scripts/big_features.py` | `close<=0 → NaN`；标签先 `replace([±inf], NaN)` 再做截面去均值；`ok` 条件改 `np.isfinite`；落盘增加 `fwd5_lag` 便于审计 |
| `scripts/big_train.py` | 3 处 `~np.isnan(Y)` → `np.isfinite(Y)` |
| `scripts/factor_scorecard.py` | 循环过滤改 `np.isfinite` |

现有 `arr.npz` / `preds.npz` / checkpoints 仍是旧面板，**下次重训会自动使用干净数据**；因为 OOS 完全干净，不建议仅为这个 bug 重跑 40 分钟。

## 四、冗余度：为什么"40/42 显著"不等于 40 个 alpha

- 因子值平均 \|corr\| **0.233**，37 对 >0.7
- PCA：解释 80% / 90% / 95% 方差需 **12 / 17 / 22** 个成分；第一主成分独吃 28.6%
- **IC 序列**平均 \|corr\| 0.304，第一主成分解释 **31.1%**，前 3 个合计 **64.7%** —— 因子涨跌高度同步
- Li & Ji 有效检验数 **19.6**（不是 42）；名义 Bonferroni 阈值约 3.23，按 M_eff 修正后降到 **3.02**
- 样本量 2614 天，IC 只要 0.03 就能显著；**显著性主要来自样本量，不是因子多**

所以正确的读法是：**找到了 1~3 个稳健、跨 11 年不衰减的独立信号（短期反转 / 过热 / 流动性冲击），并用 42 种方式重复描述了它。**

## 五、经济显著性（最弱的一环）

- 单因子十分位多空（D10−D1）5 日仅 **0.1~0.9 个百分点**（强因子 0.5~0.9），年化约 1~9%
- 换手 **43%/5 日**（中位 38%）→ 年化换手约 2000%；此前已验：20bp/边勉强可行，**50bp/边直接转负**
- 组合十分位结构：D1 **-0.990%**、D2 -0.159%、D3~D10 几乎平（+0~0.34%）→ **避雷器，不是选股器**
- 纯多头 top10% 超额为负（-2.9~-5.4%）；只有"剔除垫底 10%"给 +3.5%/年、跟踪误差 1.7%

一句话：**这是风险因子，不是收益因子。** 正确用法是给现有组合装过滤器，不是拿它选股。

## 六、关于 Muon 优化器

你提的 Muon 属于**训练器改动，不改变上面任何一条因子评价结论**。实现要点：

- Muon 只对 **2D 隐层权重矩阵**做 Newton–Schulz 正交化，`embedding / RMSNorm / head / bias` 仍走 AdamW
- 学习率通常要比 AdamW 高 5~10 倍，需配 weight decay；正交化 5 步迭代即可
- 当前 TF 是 `seq40 / d96 / 2层 / 4头` 的小模型，参数量小，Muon 相对 AdamW 的收益有限
- **瓶颈是信号天花板（IC ~0.1）和交易成本，不是优化器**。建议下次重训时顺手做 A/B（3 seed 对比 OOS IC 与训练稳定性），不必单独为它跑一轮；LGBM 是树模型，用不上
