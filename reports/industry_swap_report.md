# 行业分类替换：统计聚类 → 申万二级

> 2026-11-06｜`scripts/swap_industry.py`、`scripts/apply_sw_industry.py`
> 结论先行：**换得对，但用途要分开**——申万适合归因/约束/可解释性，不适合做因子中性化的分组。

## 一、为什么要换

原面板的行业来自 `ind_roll.parquet`：每年只用**上一年及以前**的 250 日收益做 PCA(10) + KMeans(31)，得到 31 个纯统计聚类。

它没有前视，但有两个硬伤：
1. **跨年 ARI 仅 0.12** —— 意味着每年几乎换一套行业，同一家公司在 2020 年是 7 号组、2021 年可能变 22 号组。「行业」失去了经济含义。
2. **不可解释** ——「第 7 组」无法对应到任何产业，无法做行业配置、无法向人解释。

申万二级是业务分类，时变慢、与市场共识一致，且 `stock_yjbb_em` 自带该字段。

## 二、怎么做的

| 步骤 | 实现 |
|---|---|
| 来源 | `sw_industry.parquet`（59467 行 / 128 个行业 / 2013-2026） |
| PIT | 按年份中点（7/1）铺到交易日，`merge_asof` 向后填充；严格不用未来年份 |
| 小行业处理 | <30 只的行业并入「其他」（仅 1 个行业 26 只受影响） |
| 编码 | 128 类 → `int8`（0-127），缺失 `-1` |
| 写入 | `arr.npz` 的 `IND`（原子替换，仅换该成员）；`panel_big.parquet` 新增 `sw_industry` 列 |
| 回退 | 原聚类数组备份在 `data/big/IND_cluster.npy`；`panel_big` 的原 `industry` 列**保留未删** |

`X` 的 42 个因子不依赖 `IND`，所以这次替换**没有改动任何因子值，也没有重训模型**——属于元数据级操作。

## 三、三个关键对比

**① 覆盖率：略降，可接受**

| | 有效样本覆盖 |
|---|---|
| 聚类 31 组 | 98.78% |
| 申万二级 128 | 96.67% |

差的 2.1% 主要是 2016-2017 年（早期财报缺「所处行业」字段）。

**② 行业对下期收益的解释力：申万近 2 倍**

| | 组间方差 / 总方差（R²） |
|---|---|
| 聚类 31 组 | 0.082 |
| **申万二级 128** | **0.159** |

这是这次替换最实在的收益。申万行业确实捕捉到了共同风险（产业链、政策、资金流），聚类只有一半。**如果要做行业风险模型、行业权重约束、行业轮动归因，申万明显更合适。**

**③ 但用于因子中性化，申万反而更差**

对 6 个核心因子做「行业内 z-score」：

| 因子 | 原始 IC(ICIR) | 聚类内中性 | 申万内中性 |
|---|---|---|---|
| illiq20 | +0.0434 (0.30) | **+0.0419 (0.42)** | +0.0355 (0.33) |
| illiq_ratio | +0.0420 (0.36) | **+0.0370 (0.43)** | +0.0310 (0.40) |
| ret20 | −0.0539 (−0.37) | −0.0538 (**−0.49**) | −0.0493 (−0.48) |
| turn20 | −0.0602 (−0.36) | −0.0568 (**−0.52**) | −0.0499 (−0.48) |
| std20 | −0.0577 (−0.36) | −0.0535 (**−0.44**) | −0.0485 (−0.44) |
| momq60 | −0.0426 (−0.30) | −0.0400 (−0.37) | −0.0350 (−0.35) |

**原因不是申万「不准」，是它太细**：128 个行业里中位数只有 26 只/日，组内 z-score 的抽样噪声把信号一起削掉了；31 个聚类组每组约 130 只，组内统计量更稳。

这其实是个反直觉的教训：**中性化的效果取决于分组内的样本量，而不是分组本身有多「正确」。**

## 四、附带跑出来的一个结果

用申万行业做「每个行业内剔除垫底 10%」（不是全市场剔除），在 2024+ 段、单边 20bp 下：

```
原始 IC            +0.1271
行业中性化 IC      +0.1197   （行业内选股能力）
行业层面 IC        +0.1024   （预测的行业均值 vs 行业平均收益）
行业内负向筛选     年化 +3.34% / 波动 1.01% / 夏普 1.32
```

比全市场剔底（+2.87% / 夏普 0.53）好看不少，但**口径不同不可直接比**：行业内剔除意味着每个行业都均匀地减一点仓，行业暴露几乎不变、换手更低、波动只有 1.01%。这是个值得单独验证的方向——它把「避雷」和「行业配置」解耦了。

## 五、建议

| 用途 | 用哪个 |
|---|---|
| 行业归因、行业权重约束、行业轮动 | **申万二级**（R² 0.159） |
| 做行业分布统计、对外解释、报告 | **申万二级**（有真实名字） |
| 因子行业中性化 | **聚类 31 组**（组内样本足），或申万**一级**（无数据时可用聚类近似） |
| 模型输入 | 不用（`X` 不含行业） |

如果以后要两全：用申万二级做归因，中性化时把 128 个行业按规模/相关性并成 30 组左右——但那样又退回聚类的老问题了，不如直接用聚类。
