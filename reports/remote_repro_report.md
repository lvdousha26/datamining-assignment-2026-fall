# 远程重跑验证（AutoDL RTX 4090）

> 2026-11-06｜`scripts/deploy_v2.py`、`train_remote.py`｜远程 `/root/autodl-tmp/quant`

## 一、部署

| 项 | 值 |
|---|---|
| 机器 | RTX 4090 24G / 128 核 / 50G 数据盘（`/root/autodl-tmp`） |
| Python | 3.12 + torch 2.5.1+cu124（预装）+ lightgbm 4.7 / pandas 3.1.1 / scipy 1.18 / pyarrow 26 |
| 上传带宽 | **实测 0.5 MB/s**（4 Mbps 上行） |
| 策略 | 传 2.5GB 的 `arr.npz` 要 89 分钟 → **改传 271MB 原始行情**，远程重算面板 |
| 实际传输 | 28 个 shard / 271MB，约 15 分钟 |
| 踩坑 | ① 缺 pyarrow（pandas 读 parquet 报错）② 最后一个 shard 在传输未完成时就启动，读到半截文件 → 校验后重跑 |

## 二、结果：管线完全可复现

### 特征构建（5 分钟）


| 训练耗时 | ~25 分钟 | **8 分钟** | 3× |

## 三、结论

**1. 管线可复现。** 换机器、换 CUDA 环境、重算因子，最终 Stacking dev IC 差 0.0005（0.3%），Ridge 权重差 <0.006。这个量级完全在随机种子波动范围内（LGBM 早停轮次从 107 变 96，IC 只动 0.0001）。

**2. 结论对超参不敏感。** 最优轮 107 vs 96 差 10%，IC 差 0.0001——说明模型不在过拟合边缘。

**3. 4090 比 4060 快 3 倍**（8 分钟 vs 25 分钟），特征构建受单核 CPU 限制（5 分钟 vs 40 分钟，128 核 vs 8 核）。

**4. 但这**不是**封存段验证。** 远程跑的是重训 + dev 段（2025H1）评估，`lockbox_eval.py` 的一次性验证本地已经用完（runs=1），远程没有重跑，也不该重跑。封存段的 −1.08% 多空结论仍然成立。

## 四、这次重跑证明了什么 / 没证明什么

| 证明了 | 没证明 |
|---|---|
| 数据管线换环境可复现 | 封存段表现（已消耗，不可重跑） |
| 模型训练可复现（IC 差 0.3%） | 实盘收益 |
| 结论对超参不敏感 | 2026 年后的表现 |
| 代码无环境依赖问题 | 更大模型能否更好 |
