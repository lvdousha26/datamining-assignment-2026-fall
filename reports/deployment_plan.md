# 落地方案：把避雷器真正用起来

> 2026-11-06｜基于 v2 封存段验证结果（`reports/pipeline_v2_report.md`）

## 0. 先讲清一个不能绕开的矛盾

**策略③持仓全是 ETF**（513100 / 512890 / 518880 / 510210 / BRK.B），而避雷器打的是**个股分数**。两者标的不重叠，不能直接"叠加优化"，也不能拿避雷器去筛 512890 的持仓。

所以落地是**两条独立的线**：

| | 策略③（主线） | 避雷器（新线） |
|---|---|---|
| 标的 | ETF | A 股个股 |
| 频率 | 月度 | 5 日 / 月度 |
| 依据 | 趋势 + 分散 | 量价风险因子 |
| 预期 | 8–10%/年，夏普 0.6–0.8 | **+1.5~2%/年超额**（打折后） |
| 状态 | **模拟盘已启动**（`tracking.csv` 有 2026-10 首次建仓：13/13/0/11/11，现金 52%） | 清单生成器已就绪，待模拟盘验证 |

**不要为了"用上模型"把两条线硬凑在一起。**

## 1. 唯一在独立段站得住的形态

封存段（2025-07~2026-10，318 日 / 63 期，完全未参与调参）：

| 形态 | 结果 | 判定 |
|---|---|---|
| **剔除垫底 10%（负向筛选）** | **+2.87%/年，波动 1.63%，夏普 0.53，换手 5.4%/期** | ✅ 唯一可用 |
| 纯多头 top10% | +3.40%/年 | ⚠️ 正但不如负向稳，D10 是小盘冷门股 |
| 多空 | **-1.08%/年** | ❌ 独立段失效，别做 |
| 直接拿模型选股 | — | ❌ 十分位 D2–D10 几乎全平 |

模型是**避雷器**，不是选股器。它的正确用途是"从你的候选池里划掉最差的 10%"。

## 2. 三种落地形态

| | 做法 | 资金门槛 | 额外换手 | 可行性 |
|---|---|---|---|---|
| **A 禁买清单（推荐）** | 每月生成 D1 名单，自有选股 / 卫星仓里凡是落在 D1 的不买、已持有的减仓 | 无 | ≈0 | ✅ 立刻能做 |
| B 指数成分增强 | 只对沪深300/中证500 成分打分，剔除垫底 10%，剩余等权 | 50–100 万（270~450 只） | 中 | ⚠️ 需单独验证 |
| C 全市场复制 | 剔除 D1 后持有约 4500 只等权 | 机构级 | 高 | ❌ 散户不可行 |

**推荐 A 的理由**：零额外换手、零资金门槛、不引入新的执行风险，而且它对应的正是封存段验证过的机制（"避开最差的一档"）。B 有个隐蔽问题——模型在全市场训练，用在指数成分上分布偏移，IC 会下降，**必须先跑一次专门的验证**再上。

## 3. 现实打折（别拿 2.87% 当预期）

封存段的 +2.87% 已经扣了 20bp/边，但那是研究口径：

| 项 | 数字 |
|---|---|
| 毛超额（反推） | ≈ 3.97%/年 |
| 20bp/边成本（已扣） | ≈ 1.1%/年（年化换手约 272%） |
| 散户实际 30bp/边 | ≈ 1.6%/年，多扣 0.5% |
| 冲击成本 / 停牌 / 涨跌停 / 成分调整 | 再扣 0.3~0.5% |
| **现实预期** | **+1.5~2%/年超额，跟踪误差 1.6~2%** |

**统计显著性**：年化超额 1.8% ÷ 波动 1.63% ≈ 1.1/√年，要 t>2 需要约 **2.5~3 年**。也就是说，第一年的正收益完全可能只是噪声，不能据此加仓。

把它当**尾部风险过滤器**（少踩雷）比当 alpha 更符合证据。

## 4. 月度操作流程

每月最后一个交易日收盘后：

```bash
cd /d/quant
python scripts/big_download.py          # 全市场行情刷新（分片断点续传，约 10 分钟）
python scripts/big_features.py          # 重建面板 / 因子（约 5 分钟）
cd scripts && python live_screen.py     # 生成当期清单 → live/screen_YYYY-MM-DD.csv
```

`big_download.py` 的 END 已改为自动取当天，不用手改日期。名称映射首次会缓存到 `data/big/name_map.parquet`。

**执行前四项检查**：

1. 清单日期是否为本月最后交易日（当前演示清单是 **2026-10-22**，到今天已有约 10 个交易日新数据，实盘前必须先刷新）
2. 剔除信号日**涨跌停 / 停牌**的股票（此前测过剔除后 IC 0.0996→0.0925，信号不依赖它们，但不可交易）
3. D1 里约 505 只，确认自己的候选池/持仓有没有落入
4. **模型权重与 Stacking 系数全程冻结**，不因为本期名单好看就重训或调阈值

## 5. 模拟盘跟踪与验收

用主目录已有的 `tracking.csv` + `evaluate_live.py` 机制，额外记录：

- 每期 D1 名单（存档 `live/screen_*.csv`）
- 因避雷器**放弃买入**或**减仓**的具体标的与价格
- 事后 5 日 / 20 日这些标的的实际收益（验证"避开得对不对"）

| 指标 | 健康值 |
|---|---|
| 执行偏离目标 | < 1% |
| 年化跟踪误差 | < 2% |
| 实际换手 | 5~6%/期（与回测一致） |
| D1 股票 5 日相对等权收益 | 应为负（这是信号有效的直接证据） |

**验收节奏**：满 12 个月看方向是否对、换手是否可控；满 24~36 个月才谈统计显著。**期间不放真钱**。若 D1 的相对收益连续两个季度不再为负，说明信号衰减，应停用而非调参。

## 6. 风控红线

- ❌ 不做多空（封存段 -1.08%，A 股也难融券）
- ❌ 不拿 D10 当"金股池"（小盘冷门、冲击成本高、封存段纯多头也不稳）
- ❌ 不用清单择时、不改策略③的仓位
- ❌ 不因为某期名单"看着准"就重训 / 调参 / 改剔除比例
- ❌ 不用当天涨停、停牌、ST 股做决策
- ✅ 只做负向筛选：不买 D1、已持有的减仓

## 7. 资金分配建议

- **策略③（ETF 主线）80–90%**：月度调仓、低换手，预期 8–10%/年，先跑模拟盘积累 track record
- **个股卫星仓 ≤10–20%**：仅用于验证避雷器，第一年全部模拟
- 避雷器的价值在于给卫星仓装"排雷器"，不是替代主线

如果资金量小到只能开一条线，**选策略③**——它的证据链更完整、执行更简单、预期收益高一个量级。

## 8. 什么时候才该重训

- 至少 **12 个月**一次，不要按月按季重训
- 重训前**必须先封存一段新的、从未看过的数据**，再跑一次性验证（复用 `lockbox_eval.py` 的机制，state 会记录运行次数）
- 若封存段 IC 跌破 0.06 或负向筛选超额转负，停用，而不是继续调模型
- 永远保留 v1 / v2 的模型与清单备份（`checkpoints_v1/`、`data/big/v1/`）
