# SVM 日频选股实验报告

日期：2026-11-05 ｜ 数据：D:/quant/data/panel.parquet（2019-07~2026-10，1772 日 × 255 只）＋ 8 因子库
脚本：`scripts/svm_daily.py`（主实验）、`scripts/svm_stack.py`（残差叠加）、`scripts/svm_daily` 内置安慰剂

## 一、实验设计

- **切分**：训练 <2023-01 ｜ 验证 2023 全年（只用于选超参）｜ 测试 2024-01+（只看一次）
- **标签**：5 日前向收益，逐日截面去均值；因子逐日 5×MAD 截尾 + z-score
- **模型**：RBF-SVR 网格（C∈{0.5,2,8} × γ∈{0.05,0.2}，ε=0.2，训练子样本 8k），
  最优超参在 12k 子样本重训；对照 = OLS / Ridge / ICIR rank 合成 / Nystroem 核岭（全样本）
- **回测**：5 日非重叠调仓（防重叠标签复利虚高）、top20% 等权、前 40% buffer、单边 20bp

## 二、IC 结果（Rank IC，括号内 NW-t）

| 模型 | IS | VAL 2023 | OOS 2024+ |
|---|---|---|---|
| OLS | +0.0708 | +0.1011 | **+0.0714** (6.5) |
| 8因子 ICIR 合成 | +0.0691 | +0.0852 | **+0.0885** (7.5) |
| RBF-SVM（验证集选参） | +0.0708 | +0.0704 | +0.0623 (6.8) |
| 核岭 Nystroem（全样本） | +0.0639 | +0.0786 | +0.0536 (6.3) |
| 安慰剂（打乱标签重训） | +0.0080 | +0.0114 | +0.0126 (2.8) |

**网格形态**：C 与 γ 越小（越平滑/越接近线性）VAL IC 越高（0.0788→0.0186 单调恶化），
最优超参落在网格最平滑角落 → 数据里没有可利用的非线性结构，模型越复杂越差。

**安慰剂说明**：打乱标签后 OOS IC 仍有 +0.013，但 5 日重叠标签使日频 IC 强自相关，
NW lag-4 低估了方差，有效独立样本约为 1/5，实际 t≈1.2，可视为噪声；
它提示所有模型的 IC 都带 ~+0.01 的流程性上行偏差。

## 三、费后回测（top20%，20bp/边）

| 模型 | 全样本 年化/夏普 | OOS 2024+ 年化/夏普 | 换手/期 |
|---|---|---|---|
| OLS | 17.99% / 0.68 | 21.30% / 0.67 | 16% |
| OLS+λ×SVM残差 (λ=0.5) | 18.21% / 0.69 | 21.41% / 0.67 | 16% |
| SVM 单独 | 8.45% / 0.30 | 13.85% / 0.48 | **29%** |
| ICIR 合成 | 10.79% / 0.38 | **25.02% / 0.84** | 13% |
| 等权基准 | 9.76% / 0.33 | — | — |

- SVM 换手 29%/期（vs 线性 13-16%），成本一年吃掉约 6.4pp
- 残差叠加无效：λ 曲线在验证集完全平坦（VAL IC 0.1011→0.1013），
  **SVM 非线性残差的 OOS IC = -0.0014 ≈ 0**（第一版脚本报的 +0.0177 是混入训练期的全样本口径，已修正）

## 四、小市值中性化（逐日对 SIZE20 截面回归取残差再回测）

| 模型 | 全样本 | OOS 2024+ |
|---|---|---|
| OLS → 去小市值 | **-0.80% / -0.12** | **0.02% / -0.07** |
| SVM → 去小市值 | 5.66% / 0.17 | 10.76% / 0.38 |
| ICIR 合成 → 去小市值 | 5.06% / 0.14 | 19.83% / 0.71 |

**这是全场最重要的发现**：
- OLS 的全部收益来自小市值暴露——按收益量级拟合系数，把最强的 SIZE20 权重放大，
  去掉小市值后归零。所谓"线性模型 18% 年化"是风格 beta，不是 alpha。
- SVM 反而更耐中性化（ε-不敏感损失天然压缩强因子权重，接近等权），去小市值后 OOS 还剩 10.8%。
- rank 类等权合成（ICIR）最耐中性化：OOS 去小市值后仍 19.8%/0.71。

## 五、结论

1. **SVM 在这个 8 因子、255 只股票的日频面板上没有增量**：IC 低于线性，超参选在最平滑角落，
   非线性残差样本外为零，换手还高 80%。ε-不敏感 + RBF 唯一"贡献"是隐式等权化。
2. **瓶颈是信号不是模型**：IC 天花板 ~0.07-0.09，核方法、非线性、全样本训练都突破不了。
3. **所有按收益量级拟合的模型（OLS/SVR）都会把组合变成小市值 bet**；
   要稳健就用 rank/等权合成，并把"去 SIZE20 后还剩多少"作为固定验收门槛。
4. 沿用之前结论：这套因子库的可用形态是 **ICIR rank 合成 + 去小市值验证 + 低换手约束**，
   机器学习扩容（树、SVM、核方法）三条路全部证伪。
