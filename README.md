**题目**：基于全市场 A 股面板的多因子选股模型——从 IC 检验到负向筛选的实证研究

**核心结论**：模型能稳定预测 5 日收益排序（5 折 CV IC **0.1041 ± 0.0094**，五折全正），
但预测力高度集中在「垫底那一撮」——A 股无法做空全市场，所以它只能做**减法**（禁买清单），
年化贡献 **+3~5%**。另外 8 条路径（SVM、多空、行业动量、基本面加成、Muon、TAA、策略轮动、业绩预告事件）
全部被证伪。

## 〇、写给同组：10 分钟看懂这个项目

> 不需要量化背景。这一节解释项目在做什么、每个黑话是什么意思，后面所有报告都在这个框架里。

**我们在干什么**：A 股有 5,000 多只股票，每天涨跌不同。我们想回答一个问题——
**今天收盘后，能不能用今天已经知道的数据，预测哪些股票未来 5 天表现差？**
如果能稳定识别出「垫底的那 10%」，只要把它们从买入名单里划掉，长期就能多赚几个点。这就是「禁买清单」。

**项目流程就四步**（对应仓库四个目录）：

```
抓数据(scripts/fetch_*) → 算因子拼成面板(scripts/big_features) → 训练模型(scripts/big_train)
→ 严格验证(scripts/purged_cv) → 输出禁买清单(scripts/live_screen)
```

**黑话对照表**：

| 术语 | 人话 |
|---|---|
| **面板 (panel)** | 一张大表：每行 = 某只股票在某一天，列 = 这天算出来的各种指标。我们的面板有 970 万行 |
| **因子 (factor)** | 表里的一列指标，比如「20 日换手率」。42 个因子 = 42 个维度给每天每只股票打分 |
| **IC** | 信息系数。因子值和未来收益的相关性，0.05 就算不错，负数说明方向反了 |
| **5 折 Purged CV** | 验证方法：把 10 年数据切成 5 段轮流当考卷，且训练段和考卷段之间留出 6 天「隔离带」防止偷看答案。防止「模型只是背下了历史」 |
| **封存段 (lockbox)** | 最后 18 个月数据封起来只在最终验证时打开一次。像考试前没见过的题。已用掉，所以新模型没法再验证 |
| **禁买清单** | 模型打分垫底的 10% 股票名单。每月更新，用法：你正常选股，只是别买名单上的 |
| **hfq（后复权）** | 处理分红送股的价格口径。用前复权会算出负价格（茅台 −143.5 元），收益符号都是反的，这是我们踩过最大的坑 |
| **CAR** | 事件后的累计异常收益。事件研究用它判断「某事件发生后股价是否系统性变差」 |
| **安慰剂** | 对照实验：拿同股票、非事件日的同样长窗口算收益对比。排除「本来就会跌」 |

**最重要的一个提醒**：本项目里「负结果」和「正结果」同样值钱。
8 条路径被证伪、行业中性化让 IC 反而下降、SMOTE 没用——这些都是认真做实验得出的结论，

### 4.3 被证伪的八条路径

SVM 日频 / SVM 截面 / 多空组合（封存段 −1.08%）/ 纯多头 top10% / 行业动量追涨（0 成本 −5.88%）
/ 基本面因子加成（5 折 4 折变差）/ Muon 优化器（与 AdamW 持平）/ 策略轮动（12 个变体全部跑输固定配置）

### 4.4 关联规则（30 条规则五族）

全部指向「短期过热 + 波动放大」：偏离均线 + 高波动（lift 2.49）、振幅扩张 + 日内强势（2.42）、
近期涨停 + 高于成本（2.40）。**`illiq` 在 184 条规则里只出现 9 次，但 ICIR 权重占 67%**——
线性加权要单调排序，关联规则要极端子集，两者互补。
